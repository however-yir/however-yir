## How To Navigate

- Start with the tables above if you want the fastest overview of what is mature, what is experimental, and what belongs to the same portfolio line.
- Read the autonomous-driving repos together: `howevercarla` for simulation, `howeverautoware` for ROS 2 stack integration, `howeverapollo` for planning/control stack work, and `howeverpilot` for end-side driving software.
- Compare `local-ai-hub`, `LZKB`, and `yourrag` together if you want to understand how I separate AI workspace, knowledge platform, and enterprise RAG/Agent delivery.
- Use `nebulacms`, `talentflow-hr`, and `aurora-mall` as the clearest Java full-stack productization examples.
