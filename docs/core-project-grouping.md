# Core Project Grouping

## 1. 目的

为避免模板仓库与小体量实验仓库稀释判断，招聘评审默认按“核心项目组”单独打分。

## 2. 核心项目组（优先评审）

### Java 后端方向

- `EduFlow`
- `talentflow-hr`
- `cloud-native-mall`
- `StudentCore`

### AI 应用开发方向

- `RAG-ReAct-Agent`
- `springboot-llm-rag-agent-demo`
- `yourrag`

## 3. 非核心仓库处理规则

- 代码量小于 500 行、模板仓库、课程演示仓库默认归入“探索仓库”。
- 探索仓库用于观察学习广度，不直接主导录用结论。

## 4. 评估权重建议

- 核心项目组：80%
- 探索仓库：20%

## 5. 招聘系统录入建议字段

- `core_projects_score`
- `core_projects_risk`
- `exploration_signal`
- `final_hire_recommendation`
